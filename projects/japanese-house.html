Japanese House

This is a 3D model of a japanese house that was mode using Blender. The model was then imported onto an explorable landscape that was made using Unity. This was then uploaded to the website itch.io, where it can be played and explored by anyone. The project was made for the course "Interactive Visualization", which is a course in the first year of Creative Technology. The goal of the course is to learn how to create interactive visualizations using different software and tools.
