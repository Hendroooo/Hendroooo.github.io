Davinci Tank

This is a 3D model of a davinci tank that was made on Blender. It was then uploaded onto an explorable landscape that was made on Unity. This was then uploaded to itch.io, where it can be played and explored by anyone. The project was made for the course "Interactive Visualization", which is a course in the first year of Creative Technology. The goal of the course is to learn how to create interactive visualizations using different software and tools.
