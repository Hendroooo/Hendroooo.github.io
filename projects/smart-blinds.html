Smart Blinds

This is a project where a smart blind and vent system was made that can operate autounomously using sensors and code that manages the system. The project was made for the course "Smart Environments", which is a course in the first year of Creative Technology. The goal of the course is to learn how to create smart environments using different software and tools, and to learn how to integrate different technologies to create a functional autonomous system.
